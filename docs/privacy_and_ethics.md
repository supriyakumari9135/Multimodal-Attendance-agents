# Privacy, Ethical Boundaries & Data Sovereignty

## 1. Fundamental Ethical Statement

> **Important:** Behavioral indicators are proxies, not proof of attention, learning, comprehension, motivation, or academic performance.
> - Never infer emotions, intelligence, or personality from faces, voices, or body movements.
> - Do not automatically grade, punish, or label students.
> - All analytical indicators exist strictly to assist teachers with instructional pacing, peer discussion breaks, and lecture rhythm.

## 2. Core Privacy Guarantees

1. **Zero External Cloud Processing**:
   All computer vision frame decoding, motion indicator calculations, and audio energy analyses execute exclusively on the local machine. No video stream, audio buffer, or biometric vector leaves the host.

2. **No Mandatory External API Keys**:
   The core application does not require any paid third-party API, external LLM key, or remote database connection.

3. **Autonomous Video Deletion**:
   When raw video files are uploaded, features and attendance intervals are extracted into lightweight statistical metrics. If `AUTO_DELETE_RAW_MEDIA` is active (default: `true`), the raw media is permanently purged immediately post-processing.

4. **Transparent Data Retention**:
   The system provides a configurable retention window (1 to 72 hours) and one-click data purging controls that remove both database records and retained media.

5. **Human-in-the-Loop Decision Making**:
   Attendance records generated by anonymous vision tracking require teacher verification to link with student rosters. Teachers can manually correct any status with an immutable audit log.

6. **Revocable Consent Tracking**:
   Students can grant or revoke specific modality consent (`video_presence`, `voice_activity`) at any time. Revoked students are excluded from camera detection metrics.
